# Guide: Moteur 17HS4401 + Driver A4988 + Arduino

## 📋 Spécifications du moteur 17HS4401

- **Type**: Moteur pas à pas bipolaire NEMA 17
- **Sorties**: 6 fils (2 phases, chacune avec 2 enroulements)
- **Courant nominal**: ~1.3A par phase
- **Angle par pas**: 1.8° (200 pas par tour)
- **Tension**: 12V (typiquement)

### Pinout des 6 fils

Le moteur 17HS4401 a généralement les couleurs suivantes:
- **Phase A**: Noir, Vert (+ mid-point)
- **Phase B**: Rouge, Bleu (+ mid-point)
- **Midpoints communs**: Orange, Jaune (optionnels)

Pour fonctionner en **BIPOLAIRE** (4 fils utilisés), tu utilises:
- Noir (A+) et Vert (A-)
- Rouge (B+) et Bleu (B-)

Les fils Orange et Jaune sont **ignorés** (midpoints, non utilisés en bipolaire)

## 🔌 Schéma de Connexion

### Brochage Driver A4988 vers Arduino

| Arduino Pin | A4988 Pin | Fonction |
|------------|-----------|----------|
| Pin 8 (DIR) | DIR | Direction (HIGH=CW, LOW=CCW) |
| Pin 9 (STEP) | STEP | Pulse (1 pulse = 1 pas) |
| GND | GND | Masse |
| GND | MS1, MS2, MS3 | Microstepping (réglé en GND pour full-step) |
| +5V | RESET | Reset (HIGH = actif) |
| +5V | SLEEP | Sleep (HIGH = actif) |

### Brochage Moteur vers A4988

| Moteur (Couleur) | A4988 Pin | Fonction |
|-----------------|-----------|----------|
| Noir (A+) | OUT1 | Phase A + |
| Vert (A-) | OUT2 | Phase A - |
| Rouge (B+) | OUT3 | Phase B + |
| Bleu (B-) | OUT4 | Phase B - |

### Alimentation Power

| Composant | Voltage | Courant Min |
|-----------|---------|------------|
| Arduino | +5V | 500mA |
| A4988 Logic | +5V | 100mA |
| A4988 Moteur | +12V | **2-3A** (important!) |

⚠️ **IMPORTANT**: Utilise une alimentation **12V/2A minimum** pour le moteur. Ne pas alimenter depuis l'Arduino!

## 💻 Code Arduino - Test Basique

```cpp
// Pins Arduino
#define DIR_PIN 8      // Direction
#define STEP_PIN 9     // Pulse step

// Paramètres moteur
#define STEPS_PER_REVOLUTION 200  // 17HS4401 = 200 pas/tour (1.8°)
#define RPM 60                      // Tours par minute
#define DELAY_MICROSECONDS 300000   // Délai entre les pas (μs)

void setup() {
  Serial.begin(9600);
  
  // Configurer les pins en OUTPUT
  pinMode(DIR_PIN, OUTPUT);
  pinMode(STEP_PIN, OUTPUT);
  
  // État initial
  digitalWrite(DIR_PIN, HIGH);  // Sens horaire initial
  digitalWrite(STEP_PIN, LOW);
  
  Serial.println("Moteur 17HS4401 + A4988 - Arduino");
  Serial.println("Prêt au test!");
}

void loop() {
  // Test 1: Tourner dans un sens
  Serial.println("Rotation horaire (10 tours)...");
  rotateMotor(10, true, DELAY_MICROSECONDS);
  delay(500);
  
  // Test 2: Tourner dans l'autre sens
  Serial.println("Rotation antihoraire (10 tours)...");
  rotateMotor(10, false, DELAY_MICROSECONDS);
  delay(500);
}

// Fonction pour tourner le moteur
void rotateMotor(int tours, bool clockwise, int delayMicroseconds) {
  int totalSteps = tours * STEPS_PER_REVOLUTION;
  
  // Définir la direction
  digitalWrite(DIR_PIN, clockwise ? HIGH : LOW);
  delay(5);  // Laisser le temps au driver de traiter
  
  // Générer les pulses
  for (int i = 0; i < totalSteps; i++) {
    digitalWrite(STEP_PIN, HIGH);
    delayMicroseconds(5);  // Pulse courte
    digitalWrite(STEP_PIN, LOW);
    delayMicroseconds(delayMicroseconds);  // Délai entre les pas
  }
}

// Fonction alternative: Tourner à vitesse variable
void rotateAtSpeed(int tours, int rpm, bool clockwise) {
  int totalSteps = tours * STEPS_PER_REVOLUTION;
  
  // Calculer le délai entre les pas
  // RPM = (60 * 1,000,000) / (STEPS_PER_REVOLUTION * DELAY_MICROSECONDS)
  int delayBetweenSteps = (60 * 1000000) / (STEPS_PER_REVOLUTION * rpm);
  
  digitalWrite(DIR_PIN, clockwise ? HIGH : LOW);
  delay(5);
  
  for (int i = 0; i < totalSteps; i++) {
    digitalWrite(STEP_PIN, HIGH);
    delayMicroseconds(2);
    digitalWrite(STEP_PIN, LOW);
    delayMicroseconds(delayBetweenSteps);
  }
  
  Serial.print("Moteur: ");
  Serial.print(tours);
  Serial.print(" tours @ ");
  Serial.print(rpm);
  Serial.println(" RPM - DONE");
}
```

## 🎯 Code Avancé - Contrôle Série

```cpp
#define DIR_PIN 8
#define STEP_PIN 9
#define STEPS_PER_REVOLUTION 200

String command = "";

void setup() {
  Serial.begin(9600);
  pinMode(DIR_PIN, OUTPUT);
  pinMode(STEP_PIN, OUTPUT);
  
  Serial.println("Commandes:");
  Serial.println("r[tours] - Rotation CW (ex: r5)");
  Serial.println("l[tours] - Rotation CCW");
  Serial.println("s[rpm]   - Vitesse RPM");
  Serial.println("p[steps] - Pas spécifique");
}

void loop() {
  if (Serial.available() > 0) {
    char c = Serial.read();
    
    if (c == '\n') {
      processCommand(command);
      command = "";
    } else {
      command += c;
    }
  }
}

void processCommand(String cmd) {
  if (cmd.length() < 2) return;
  
  char action = cmd[0];
  int value = cmd.substring(1).toInt();
  
  switch(action) {
    case 'r':  // Rotation horaire
      rotateSteps(value * STEPS_PER_REVOLUTION, true);
      break;
    case 'l':  // Rotation antihoraire
      rotateSteps(value * STEPS_PER_REVOLUTION, false);
      break;
    case 'p':  // Pas direct
      rotateSteps(value, true);
      break;
    default:
      Serial.println("Commande inconnue");
  }
}

void rotateSteps(int steps, bool clockwise) {
  digitalWrite(DIR_PIN, clockwise ? HIGH : LOW);
  delay(5);
  
  for (int i = 0; i < steps; i++) {
    digitalWrite(STEP_PIN, HIGH);
    delayMicroseconds(5);
    digitalWrite(STEP_PIN, LOW);
    delayMicroseconds(300000);  // 300ms entre les pas
  }
  
  Serial.print("✓ Complété: ");
  Serial.print(steps);
  Serial.println(" pas");
}
```

## ⚡ Paramètres Importants

### Délai entre les pas (Speed Control)
```
Délai (μs) = (60,000,000) / (RPM * STEPS_PER_REVOLUTION)

Exemples pour 17HS4401 (200 pas):
- 60 RPM   → 5,000 μs
- 120 RPM  → 2,500 μs
- 300 RPM  → 1,000 μs
```

### Microstepping
Par défaut, le A4988 utilise le **full-step** (200 pas). Pour le micro-stepper:
- MS1=LOW, MS2=LOW, MS3=LOW → Full-step (200 pas)
- MS1=HIGH, MS2=LOW, MS3=LOW → Half-step (400 pas)
- MS1=LOW, MS2=HIGH, MS3=LOW → 1/4 step (800 pas)
- MS1=HIGH, MS2=HIGH, MS3=LOW → 1/8 step (1600 pas)
- MS1=HIGH, MS2=HIGH, MS3=HIGH → 1/16 step (3200 pas)

Relie MS1, MS2, MS3 à GND pour full-step (plus de couple, moins de précision).

## 🔧 Troubleshooting

| Problème | Solution |
|----------|----------|
| Moteur ne tourne pas | Vérifier les connexions, notamment GND commun |
| Moteur chauffe | Réduire RPM ou vérifier l'alimentation 12V |
| Mouvement saccadé | Augmenter le délai entre les pas |
| Pas d'alimentation | Vérifier l'alimentation 12V (min 2A) |
| Bruit bizarre | Vérifier les fils Orange/Jaune ne sont pas connectés |
